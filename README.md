# ระบบตรวจสอบตู้ขนส่งสินค้าและสภาพสินค้า (Container & Cargo Inspection App)

เว็บแอปพลิเคชันสำหรับเจ้าหน้าที่คลังสินค้าและฝ่ายตรวจรับสินค้า พัฒนาขึ้นจากแบบฟอร์มกระดาษจริง รองรับการใช้งานบนโทรศัพท์มือถือ แท็บเล็ต และคอมพิวเตอร์อย่างสมบูรณ์แบบ

---

## 🌟 ฟังก์ชันเด่น (Key Features)

1. **เช็กลิสต์ตรวจตู้และสินค้าครบ 14 ข้อ**:
   - ออกแบบปุ่มสัมผัสขนาดใหญ่ กดเลือกผลตรวจ (ดี/ไม่ดี, แน่น/ไม่แน่น, มี/ไม่มี) ได้สะดวกรวดเร็ว
   - มีปุ่มทางลัด **"เลือกผ่านทุกข้อ (Pass All)"** สำหรับตู้สภาพดี ช่วยประหยัดเวลา
   - มีระบบแจ้งเตือนสรุปผลรับ/ไม่รับอัตโนมัติหากมีรายการที่ไม่ผ่าน

2. **ระบบกล้องและภาพถ่ายหน้างาน (Photo Capture)**:
   - กดปุ่ม **"ถ่ายรูปจากกล้อง"** เพื่อเปิดกล้องมือถือถ่ายภาพหน้างานได้ทันที
   - จัดหมวดหมู่ภาพอัตโนมัติ: หมายเลขตู้/ป้ายทะเบียน, ซีลตู้ (Seal No.), สภาพตู้, สินค้าเสียหาย, สำเนาใบ Invoice
   - บีบอัดรูปภาพให้อัตโนมัติ ป้องกันปัญหาเครื่องช้าหรือความจำเต็ม

3. **ตารางบันทึกสินค้าเสียหาย (Damage Log)**:
   - เพิ่ม/ลบรายการสินค้าเสียหายได้ไม่จำกัด (รหัสสินค้า, สาเหตุ, จำนวน)

4. **กระดานลงลายมือชื่อดิจิทัล (Digital Signature Pad)**:
   - เซ็นลายมือชื่อด้วยนิ้วมือหรือปากกาสไตลัสบนหน้าจอมือถือได้โดยตรง
   - แยกช่องลายเซ็น **ผู้รับสินค้า** และ **Warehouse Supervisor**
   - มีปุ่มล้างลายเซ็นหากต้องการเซ็นใหม่

5. **การออกรายงาน PDF และพิมพ์เอกสาร (Print & Export)**:
   - สั่งพิมพ์ หรือบันทึกเป็น PDF สวยงาม จัดรูปแบบตามมาตรฐานเอกสารกระดาษ A4 เดิม
   - แนบลายเซ็นและรูปถ่ายลงในรายงานครบถ้วน

6. **ระบบประวัติย้อนหลังและการทำงานแบบ Offline**:
   - บันทึกข้อมูลลงในเครื่องทันที แม้ไม่มีสัญญาณอินเทอร์เน็ตในลานตู้คอนเทนเนอร์
   - ค้นหาประวัติย้อนหลังตามเลขตู้, ทะเบียน, หรือวันที่ตรวจรับ
   - ส่งออกข้อมูลประวัติเป็นไฟล์ **Excel / CSV** ได้ในคลิกเดียว

7. **สรุปส่ง LINE**:
   - มีปุ่มสร้างข้อความสรุปผลการตรวจรับพร้อมอิโมจิ คัดลอกส่งเข้ากลุ่ม LINE ทำงานได้ทันที

> ข้อมูลประวัติการตรวจรับจะบันทึกใน `localStorage` ของเบราว์เซอร์ที่ใช้งาน จึงเหมาะกับเว็บเดโมบน Vercel และทำงานได้โดยไม่ต้องมีฐานข้อมูลหรือ API แต่ข้อมูลจะไม่แชร์ข้ามอุปกรณ์/เบราว์เซอร์ และอาจหายได้หากผู้ใช้ล้างข้อมูลเว็บไซต์

## 🚀 วิธีการเปิดใช้งาน

### 1. ใช้งานบนคอมพิวเตอร์ / แท็บเล็ต
- ดับเบิลคลิกเปิดไฟล์ `index.html` ผ่านเบราว์เซอร์ **Google Chrome**, **Microsoft Edge**, หรือ **Safari** ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเสริม

### 2. นำไปเปิดใช้งานบนโทรศัพท์มือถือของทีมงาน
- **วิธีที่ 1 (แนะนำ - โฮสต์ออนไลน์ฟรี)**: อัปโหลดโฟลเดอร์นี้ขึ้น [Netlify Drop](https://app.netlify.com/drop), [Vercel](https://vercel.com), หรือ GitHub Pages ได้ทันที เพราะเป็นเว็บ static ที่ไม่ต้องมีฐานข้อมูลหรือ API
- **วิธีที่ 2 (แชร์ผ่านวง Wi-Fi เดียวกัน)**: รันเว็บเซิร์ฟเวอร์ในคอมพิวเตอร์ แล้วเปิดผ่าน IP เครื่อง เช่น `http://192.168.1.X:8080`
- **วิธีติดตั้งเป็นแอปบนมือถือ (PWA)**: เมื่อเปิดผ่านเบราว์เซอร์บนมือถือ (Chrome/Safari) ให้กดเมนูจุดสามจุด หรือปุ่มแชร์ แล้วเลือก **"เพิ่มลงในหน้าจอโฮม (Add to Home Screen)"** ตัวระบบจะกลายสภาพเป็นแอปพลิเคชันเต็มจอเสมือนแอปจริง
